# Ballsdex-Packinstaller
Allows you to install 3rd party packages directly on discord for Ballsdex V3

Please don't install yet, this is still in development
```toml
# PackInstaller
[[ballsdex.packages]]
location = "git+https://github.com/GlitchedGlitch/Ballsdex-Packinstaller.git#dev"
path = "packinstaller"
enabled = true
```
